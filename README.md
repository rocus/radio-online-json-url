This repository is made to supply a list of known radio stations per country. The source is the latest (at the moment of creation of these files) version of the radio-browser database. 

(see http://backups.radio-browser.info/)

It is not meant to be human readable (although you can "read" the json file) but is meant to be used by an other program as a source for listing radio stations of a specific country.

My plan is to generate these json files several times per year. But if you find errors or want a new station added you must change that somehow at the radio-browser site.

(see https://gitlab.com/radiobrowser/radio-database)

I use these json files as a source for a plugin I made for Streamtuner-ng. 

(see https://github.com/IronWolve/StreamTuner-ng)

You can see that plugin as a repository on my github page.

(see https://github.com/rocus/country-stations)
